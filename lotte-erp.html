// Project

롯데케미칼 SAP S/4HANA 발표자료

광운대학교 경영대학 ERP개론 팀프로젝트. Claude Code 를 활용한 바이브코딩으로, 49장 분량의 발표 자료를 3일 만에 혼자 완성했습니다.

// Overview

기획·디자인·자동화·도메인 분석을 한 명이 3일에 완성한 발표 자료

롯데케미칼을 사례 기업으로 두고, SAP S/4HANA 기반의 통합 ERP 고도화 시나리오를 제안하는 ERP개론 팀프로젝트입니다. 단순한 슬라이드 정리가 아니라, 디자인 시스템과 자동화 빌드, 도메인 분석을 모두 한 명이 책임지는 방식으로 진행했습니다.

초반에 디자인 토큰·컴포넌트·발표 구조를 먼저 정합한 뒤, 이후의 슬라이드 빌드는 Claude Code 를 활용해 자동화했습니다. 그 결과 49장이라는 분량을 3일이라는 짧은 기간 안에 일관된 품질로 완성할 수 있었습니다.

앞으로 비슷한 규모의 발표 자료를 만들 때, 이번에 정합한 디자인 구조와 자동화 흐름을 재사용해 더 적은 노력으로 같은 수준의 결과물을 만들 수 있는 자산이 되었다고 생각합니다.

// Contents

발표 흐름

발표는 ERP개론 과제 보고서의 Step 1~5 순서를 따릅니다. 각 Step 의 상세 내용은 추후 본 페이지에 보강할 예정입니다.

01

Step 1 · 진단

롯데케미칼의 현재 상태와 문제 정의. 10장 분량.

02

Step 2 · 방향

SAP S/4HANA 도입의 전략적 방향과 통합 압력 정리. 11장 분량.

03

Step 3 · 시나리오

통합 ERP 고도화 시나리오의 핵심 설계. 14장 분량으로 가장 비중이 크다.

04

Step 4 · 실행

실행 로드맵과 트레이드오프 관리. 8장 분량.

05

Step 5 · 결과

기대 효과와 리스크, SAP 중심 플랫폼으로서의 의의. 8장 분량.

// Approach

어떻게 만들었나

바이브코딩의 핵심은 "정합 후 자동화"입니다. 초반에 흔들리지 않을 토대를 만들어두면, 이후의 분량은 자동화로 감당할 수 있습니다.

01

디자인 시스템 정합

디자인 토큰, 컴포넌트, 톤 위계, 16:9 스테이지·리빌 컨트롤러까지 먼저 확정해 49장 전체가 같은 언어로 보이도록 했습니다.

02

슬라이드 빌드 자동화

Claude Code 를 활용해 슬라이드 빌드를 자동화했습니다. 정합된 디자인 위에서 분량을 빠르게 채우면서도 품질을 균일하게 유지할 수 있었습니다.

03

도메인 분석

롯데케미칼에 대한 심층 조사와 ERP 전문가 관점의 분석을 병행했습니다. 화면이 예뻐 보이는 것이 아니라, 내용이 맞는 발표를 목표로 했습니다.
