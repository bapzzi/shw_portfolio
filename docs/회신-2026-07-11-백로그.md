## 4. 브리프에서 벗어난 판단 (전부 기록)

1. **"케이스 요약의 CSS 목업" — 교체 대상이 존재하지 않음.** CasePage에는 CSS 목업이 없다
   (요약 표 + 타임라인 + 터미널뿐). 승인 시안·디자인규칙 §0 모두 "카드=스크린샷"은 홈 카드에만
   해당. 케이스 페이지에 스크린샷을 **새로 추가하는 것은 시안 밖 설계 결정**이라 하지 않았다.
   → 홈 3카드만 교체. 케이스 페이지에도 넣을지는 owner 결정.
2. **홈 히어로 목업(m1/m2)은 유지** — 브리프 대상 아님 + 디자인규칙 §히어로가 목업 허용.
3. **adsp-board 썸네일 = 로그인 게이트 화면.** 라이브 홈이 이름/PIN 입장 화면이라 썸네일이
   밋밋하다(크림 배경 + 폼 하나). 내부 대시보드 캡처는 PIN 인증 필요 = 실행 세션 권한 밖.
   브리프 문언("홈을 캡처")대로 게이트 화면을 사용. 교체 원하면 owner 결정 필요.
4. **shot-adsp-board.webp(2.8KB)는 vite가 데이터 URI로 인라인**(4KB 미만 기본 동작) —
   dist 파일 목록에 없는 것은 정상.
5. **CSS 기존 규칙 조정**: `.card .thumb img` → `.card .thumb .mock img`. 기존 규칙은 프레임
   없는 bare img용(자체 보더)이라 프레임과 이중 보더 발생 → 프레임 내 이미지용으로 수정.
   높이는 `calc(100% - 35px)`(프레임 상단 바 제외).
6. **검증 캡처 1차 오염 → 정정**: preview 기본 포트 4173을 **다른 세션의 서버(erp-club 페이지)**가
