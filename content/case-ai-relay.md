## 타임라인

### ◆ 문제 정의 → 비동기 요청 큐 (6월 중)
- **문제**: 계정 공유 없이 AI 산출물을 전달해야 함. 사용자는 하루 1~2번만 접속 가능
- **AI활용**: `As-Is/To-Be 분석` — 제약이 표준에 새겨짐: "절대 되묻지 마라, 1턴 완결, 부족분은 (가정) 표기"
- **결정**: 실시간이 아닌 **비동기 요청 큐** 웹앱
- **⊘기각**: 채팅/챗봇 방식 — 산출물 중심 회차 구조로 ("채팅 폐기" 명시)
- **결과**: 요청 폼 7칸 구조화(요구공학 "모호하지 않음") ⊘기각 자유 텍스트 입력

### ◆ 생성표준의 진화 — v3→v6, 4회 개정 (6/26~28)
- **문제**: AI 산출물(영상 광고 기획서) 품질이 들쭉날쭉
- **AI활용**: 표준 문서가 프롬프트를 통제 — "얕게 여러 개 말고 깊게 하나" `(가정) 표시로 환각 통제` `"교육 정보는 네가 만들지 마라"(날짜 환각 방지)`
- **결정**: 단일원천(SSOT) 선언 — "어긋나면 docs/07을 신뢰". 사용자 피드백 3건 전부 표준에 반영(원문 왜곡 금지 규칙)
- **결과**: v3 얕은 5개안 → v6 3단계 파이프라인+키컷 프롬프트

### ◆ 역할 재정의 — 운영자 UI 제거 (6/28)
- **문제**: 실사용자 피드백 원문 — "어디서 뭘 하는지 헷갈린다, 처리시작을 누가 누르는지 모르겠다"
- **AI활용**: `피드백 원문 보존 → 역할 혼동 진단` `내부 enum 보존 + 표시만 친화 라벨(데이터와 표현 분리)`
- **결정**: 운영자 화면 제거, 사용자 단일뷰 + 3단계 트리아지(확인하세요/작업 중/완료)
- **⊘기각**: 운영자+사용자 겸용 앱(기존 구조)

### ◆ v2.0.0 — 무인 자율 세션의 하루 3릴리스 (6/29)
- **문제**: 디자인 전면 개편 + PDF 내보내기를 하루에
- **AI활용**: `무인 자율 세션(로컬 커밋만·push 금지)` — **배포 게이트는 사람**(before/after 스크린샷 검토 후)
- **결정**: PDF = 브라우저 print-to-pdf(무의존)
- **⊘기각**: jsPDF·react-pdf — 번들 수백 kB + 한글 폰트 임베딩 난제. '안 함' 원장: 다크모드(사용자 폰 단일 환경, 재검토 조건 명시)
- **결과**: v1.0.0→v2.0.0 하루 3릴리스·롤백 0 · 테스트 106 · PDF 11페이지 헤드리스 검증 · 접근성 대비 5.02:1(AA)

### ◆ 실증 — 공모전 풀 파이프라인 완주 (7/7)
- **문제**: 회차(1·2·3차) 설계가 실전에서 작동하는가
- **결과**: 퀴즈노스 20주년 공모전 — 기획안→각색→키이미지 프롬프트 **1~3차 완주** = 단계 승인 게이트의 비동기 매핑 실증
