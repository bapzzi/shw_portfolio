## 타임라인

### ◆ MVP → 라이브 (6월 말)
- **문제**: 주 1회 오프라인·예습 기반 스터디, 각자 어디까지 했는지 아무도 모름
- **AI활용**: `MVP 구축` `opus 최종 리뷰 — Critical 0건 판정 후 머지`
- **결과**: erpstudy.vercel.app 라이브 → 독립 repo 분리(Tier1)

### ◆ 절(節) 기반 재설계 (7/1 · 커밋 61)
- **문제**: "어느 절이 약한지"를 못 봄 + 교재 20일 계획이 기출 암기형 시험과 불일치
- **AI활용**: `스펙 설계` `교재 555장 병렬 판독 → 콘텐츠 제작` `전수 검증(JSON·정답인덱스·경계·렌더)`
- **결정**: 진도 원자 단위 = 절(과목3→장8→절29), 25 공부일 재배분 + 페이지 앵커
- **⊘기각**: Day 단위 구 스펙 — 문서에 "이 스펙은 …을 대체한다" 명시 폐기
- **결과**: 절 기반 구조 + 문항 316 슬롯

### ◆ v2.0.0 — 지표체계 개편 (7/2 · 커밋 74)
- **문제**: "진도 0%인데 준비도 73%" — 지표 이름이 화면마다 다른 세계
- **AI활용**: `실계정 재현으로 근본원인 확정 — 추측으로 고치지 않는다` `지표 사전 통일` `TDD(완료 로직 중앙화)`
- **결정**: 완료 = 정리본 체크 AND 퀴즈 100%. 준비도 공식은 **사용자가 직접 수정**(19.8→1.2 체감 일치)
- **⊘기각**: 공들여 만든 수동 기출입력 기능 — 2주 만에 자체 드롭(마이그 0014, 데이터 원천 일관성 우선)
- **결과**: 테스트 67→132

### ◆ 감독 체계 구축 (7/5)
- **문제**: "뭐가 효율적인지 판단 근거가 안 남는다"
- **AI활용**: `분석·제안=AI / 결정·소통=사람 — 역할 경계를 스펙에 명문화` `읽기전용 집계 스크립트(해석 없음)`
- **결정**: 주간 감독 리포트, 자동 스케줄 없음(매주 사람이 트리거 — 통제>자동화)
- **⊘보류**: 공지 활용 제안 — 사용자 판단 "카톡 중심 유지"
- **결과**: W27 발견 "주간 활성 1/8명" → 로그인 로그 즉시 채택·배포(마이그 0018)

### ◆ v2.3.0 — 진행도 일차 기반 전환 (7/7)
- **문제**: 지표 17% ↔ 사용자 체감 8% (2일차, 계획대로 했는데)
- **AI활용**: `산술 검증 54/316=17.1%` `판정 3안 분기 → 사용자 결정` `서브에이전트 리뷰 → Critical 2건 수정`
- **결정**: 절학습=자동 / 점검·복습=수동 체크 / 모의·기출=응시 자동
- **⊘기각**: 문항 커버리지 표시(내부 재료로 강등) · 달력 선형 보간("선형 보간 은퇴" 커밋)
- **결과**: 테스트 **159 GREEN** · 마이그 0019 · 배포
