// Project

대학 학업 관리·자동화 시스템

한 학기 6과목의 강의자료·필기·시험대비를 흩어진 PDF 더미가 아니라 하나의 데이터베이스로 관리했습니다. Claude Code 로 강의 PDF 처리 파이프라인을 자동화하고, 과목별 스키마와 스킬로 정리 방식을 표준화한 개인 학업 운영 프로젝트입니다.

// Overview

"공부를 데이터로 다룬다" — 학업을 운영 가능한 시스템으로

매 학기 강의 PDF, 필기, 발표자료, 시험 자료가 폴더마다 흩어지는 문제를 풀고 싶었습니다. 그래서 학업 자체를 하나의 프로젝트로 보고, 입력(강의자료) 부터 가공(정리본)·산출(시험 대비)까지 흐르는 파이프라인으로 설계했습니다.

핵심은 두 가지입니다. 첫째, 반복 작업(PDF 를 이미지로 바꾸고 노트 틀을 만드는 일)은 Python 스크립트로 자동화했습니다. 둘째, 과목마다 다른 시험 형태에 맞춰 정리 방식을 과목별 스키마와 스킬로 표준화해, 같은 명령으로 과목마다 다른 결과가 나오도록 했습니다.

학기가 끝난 뒤에는 원본 강의자료를 정리하고, "무엇을 배웠나"가 아니라 "어떻게 관리했나"라는 운영 방식 자체를 아카이브로 남겼습니다. 다음 학기에도 같은 구조를 그대로 재사용할 수 있는 자산이 되었습니다.

// Contents

학업 처리 파이프라인

강의자료 한 개가 들어오면, 아래 다섯 단계를 거쳐 시험 대비 자료까지 이어집니다. 뒤로 갈수록 정보가 압축되고 시험 형태에 맞게 재구성됩니다.

01

Step 1 · 수집

바탕화면에 쌓인 강의 PDF 를 과목별 입력 폴더로 모읍니다.

02

Step 2 · 변환 (자동화)

Python 스크립트가 PDF 를 슬라이드 이미지와 필기용 노트 틀로 자동 변환합니다. 이미 처리한 파일은 건너뜁니다.

03

Step 3 · 정리

정리 스킬이 과목 서식에 맞춰 강의 내용을 구조화된 정리본으로 만듭니다.

04

Step 4 · 시험 대비

시험 스킬이 내 필기를 기준으로 과목별 시험 형태에 맞춘 최종 정리본을 생성합니다.

05

Step 5 · 운영

과목별 메타 스키마와 시행착오 로그로 전체 과정을 일관되게 표준화·개선합니다.

// Approach

어떻게 만들었나

반복은 코드로, 판단은 스키마로 나눴습니다. 자동화가 분량을 감당하고, 과목별 규칙이 품질을 책임지는 구조입니다.

01

변환 자동화 스크립트

설정 파일과 처리 로그를 기반으로, 같은 PDF 를 두 번 변환하지 않는 멱등(idempotent) 파이프라인을 만들었습니다. 미리보기(dry-run)로 결과를 먼저 확인한 뒤 실행합니다.

02

스킬 시스템

"과목 생성 → 업로드 → 정리 → 시험 정리" 4단계를 각각 스킬로 만들어, 자연어 명령 한 줄로 정해진 작업이 일관되게 실행되도록 했습니다.

03

과목별 데이터 스키마

과목마다 기본 정보·시험 유형·전략·문제 예시를 담은 메타 레코드를 두고, 이 레코드가 정리·시험 스킬의 출력을 과목마다 다르게 이끌도록 설계했습니다.
